YouTube Recorder

A personal tool for monitoring selected YouTube channels, capturing available livestreams and uploading the user's recordings to their Google Drive.

The user authorizes Google Drive through rclone with their own OAuth client. The recommended drive.file permission lets the tool manage files created or authorized for this app. Recordings uploaded to Drive remain private unless the user changes their sharing settings.

The software runs on a computer or service selected by the user. Optional Gofile or GitHub Release backups and Telegram link notifications can be configured separately. Those services have their own access, retention and usage rules. Public backup links may be accessible to anyone who has them.

Recording and upload availability depend on the source stream, the user's authorization, connectivity and the selected hosting service. The project does not promise uninterrupted capture.
